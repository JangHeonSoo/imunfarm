양파는 마늘보다 조금 늦게 밭에 들어간다. 마늘을 다 심고 나서 "양파는 언제 심지" 하고 달력을 보면 대개 10월 중순이다. 그런데 양파는 날짜를 놓쳤을 때 손해가 두 방향으로 온다. 너무 일찍 크게 심으면 봄에 꽃대가 올라오고, 너무 늦으면 뿌리가 덜 내린 채 땅이 얼어 모종이 솟아오른다.

> 한 줄 결론: <strong>양파는 하루 평균기온이 15℃ 안팎으로 내려올 때, 45–60일 기른 모종을 심는다.</strong> 내륙은 10월 중하순, 남부는 11월 상순, 제주 중만생종은 11월 상하순이 기준이다. 모종은 줄기 굵기 6–7.5mm, 키 25–30cm, 잎 4장짜리를 고르고 3cm 깊이로 심는다. 한 평(3.3㎡)에 약 110주가 들어간다. 2026년 10월 2일 KAMIS 서울 양파 상품 15kg 도매가는 18,800원이다.

> 직접 계산해 보기: 시장별로 받을 수 있는 금액은 [농산물 시장별 판매 금액 계산기](/tools/produce-market-calculator/?item=onion)로 비교한다.

## 1. 양파 심는 시기는 언제인가.

농촌진흥청은 2026년 8월 보도자료에서 "하루 평균기온 15℃ 무렵에 45–60일 기른 모종을 아주심기"하라고 안내했다. 남부 중만생종은 9월 18일 이후 씨를 뿌려 11월 상순부터 심는 일정이다. 날짜보다 기온이 기준이라 북쪽·내륙일수록 빨리, 남쪽·제주일수록 늦게 심는다.

| 구분                  | 정식(아주심기) 시기     | 근거                       |
| --------------------- | ----------------------- | -------------------------- |
| 조생종                | 10월 상중순             | 농진청 주간농사정보        |
| 중생종                | 10월 상순–11월 상순     | 농진청 주간농사정보        |
| 만생종                | 10월 하순–11월 중순     | 농진청 주간농사정보        |
| 남부 중만생종         | 11월 상순부터           | 농진청 2026년 8월 보도자료 |
| 전북 정읍 (일반 모종) | 10월 중하순             | 정읍시농업기술센터         |
| 제주 조생 / 중만생    | 10월 중순 / 11월 상하순 | 제주농업기술원             |

경기·충청 같은 중부 지역 날짜를 따로 적은 공식 자료는 찾지 못했다. 다만 기준이 "평균기온 15℃"이므로 중부 내륙은 정읍보다 조금 이른 10월 중순부터 보면 된다. 동네 기온이 아침 한 자릿수로 내려가는 주가 오면 늦어도 그 주에는 심는 편이 안전하다.

## 2. 좋은 양파모종은 굵기로 고른다.

| 항목      | 좋은 모종           | 피할 모종                           |
| --------- | ------------------- | ----------------------------------- |
| 줄기 굵기 | 6–7.5mm (연필 굵기) | 너무 굵은 묘: 봄에 꽃대·쪼개짐 위험 |
| 키        | 25–30cm             | 웃자라 휘청거리는 묘                |
| 잎 수     | 4장                 | 잎이 2장 남짓인 가는 묘             |
| 육묘 기간 | 45–60일             | 오래 묵힌 묘                        |

농사로의 양파 정식 요령은 잎집(줄기) 굵기 6–7.5mm, 키 25–30cm, 잎 4장을 좋은 모종으로 든다. 굵은 모종이 튼튼해 보여도 일찍 심으면 겨울 전에 너무 자라 봄에 꽃대(추대)가 올라오거나 알이 쪼개지는 분구가 늘어난다. 반대로 가는 모종은 뿌리가 약해 겨울 추위와 서릿발에 약하다.

양파모종을 살 때는 한 판에 몇 구(주)가 들었는지 먼저 본다. 같은 값이라도 200구와 400구짜리는 한 주당 값이 두 배 차이 난다. 조생종은 봄에 일찍 먹고, 중만생종은 6월에 캐서 오래 저장한다. 텃밭이라면 저장용 중만생종이 무난하다. 판매처마다 값이 달라 이 글에서는 모종 가격을 숫자로 적지 않는다.

## 3. 심는 깊이와 간격, 한 평에 몇 주인가.

| 항목         | 기준                                           |
| ------------ | ---------------------------------------------- |
| 깊이         | 3cm. 곧게 세우고 흙을 가볍게 눌러 준다         |
| 두둑         | 폭 120cm에 6줄, 이랑 높이 20cm 이상            |
| 포기 사이    | 15cm 안팎 (줄 사이 15–20cm, 포기 사이 10–15cm) |
| 10a(300평)당 | 약 33,000주                                    |
| 한 평(3.3㎡) | 약 110주                                       |
| 늦게 심을 때 | 조금 더 깊게 심는다                            |

농사로 기준 10a에 33,000주라면 한 평에 약 110주다. 텃밭 두 평이면 모종 200구짜리 한 판이 조금 넘게 든다. 깊게 심으면 알이 길쭉해지고 크기가 덜 큰다. 얕게 심으면 겨울에 들뜨기 쉽다. 흰 줄기가 흙에 묻히고 잎이 갈라지는 자리는 흙 위에 남는 정도가 3cm 안팎이다.

멀칭은 심기 전에 투명 또는 흑색 비닐을 덮고 구멍에 심는다. 마늘용으로 많이 쓰는 0.015mm 흑색 유공 비닐은 양파에도 쓴다. 바람에 비닐이 들리면 모종이 상하므로 가장자리를 흙으로 묻고 고정핀을 박는다.

## 4. 밑거름은 심기 전에 넣는다.

| 비료 (10a 기준) | 전체 양 | 밑거름으로 넣는 양 |
| --------------- | ------- | ------------------ |
| 퇴비            | 3,000kg | 전량               |
| 요소            | 52.2kg  | 17.4kg             |
| 용성인비        | 38.5kg  | 전량               |
| 염화칼리        | 25.6kg  | 15.2kg             |

농사로 정식 요령의 표다. 나머지 요소와 칼리는 봄에 웃거름으로 나눠 준다. 웃거름은 땅 온도가 4℃ 안팎으로 안정되는 이른 봄에 시작해 3월 하순 전에 끝낸다. 늦게까지 질소를 주면 알이 무르고 저장 중에 잘 썩는다. 밭은 18cm 이상 깊이 갈고, 산성 땅이면 석회를 함께 넣는다. 정확한 양은 농업기술센터 토양검정 결과를 따르는 것이 가장 정확하다.

## 5. 월동 관리는 서릿발이 핵심이다.

서릿발은 땅속 물이 얼면서 흙을 밀어 올리는 현상이다. 뿌리가 덜 내린 모종은 흙째 들려 뿌리가 끊기고 말라 죽는다. 농진청 자료는 새 뿌리가 덜 자랐을 때 땅이 얼거나, 물이 잘 안 빠지는 밭, 겉흙이 얕은 밭에서 많이 생긴다고 설명한다.

| 상황                  | 할 일                                     |
| --------------------- | ----------------------------------------- |
| 심은 뒤 2–3주         | 뿌리 3–4개, 길이 10cm 이상 내리게 물 관리 |
| 모종이 솟아오름       | 눌러 주고 흙을 덮는다                     |
| 솟은 모종이 넓게 죽음 | 남은 모종으로 보식한다                    |
| 물 빠짐이 나쁜 밭     | 이랑을 높이고 배수로를 판다               |

제주농업기술원 자료는 뿌리가 3–4개, 길이 10cm 이상 내린 양파는 동해와 서릿발을 견디고 영하 8℃까지는 얼어 죽지 않는다고 적는다. 그래서 정식 시기를 지키는 것이 월동 관리의 절반이다. 땅이 얼기 전에 뿌리를 충분히 내릴 시간을 주는 것이다.

## 6. 농가는 언제 팔아야 더 받나.

2026년 10월 2일 KAMIS 중도매인 판매가다.

| 지역 | 양파 상품 15kg | 1년 전 같은 날 | 2026년 6월 19일 |
| ---- | -------------: | -------------: | --------------: |
| 서울 |       18,800원 |       18,300원 |        11,000원 |
| 부산 |       18,400원 |       18,000원 |        10,300원 |
| 대구 |       16,800원 |       18,200원 |        11,300원 |
| 광주 |       19,100원 |       18,500원 |         9,750원 |
| 대전 |       21,800원 |       18,300원 |        11,600원 |

서울 기준 지금 값은 1kg에 약 1,250원이다. 햇양파를 캐던 6월 19일(11,000원)보다 70% 넘게 높다. 2016년부터 올해까지 서울 월평균을 이어 보면 이 흐름은 해마다 비슷하다. 5월(평균 13,347원)과 6월(13,734원)이 가장 싸고, 저장 양파가 줄어드는 2–3월(19,607–19,869원)이 가장 비싸다.

| 달 (서울 월평균) | 2016–2026년 평균 |   2026년 |
| ---------------- | ---------------: | -------: |
| 5월              |         13,347원 | 10,867원 |
| 6월              |         13,734원 | 11,067원 |
| 8월              |         16,946원 | 18,835원 |
| 10월             |         16,831원 | 18,800원 |
| 2월              |         19,607원 | 17,947원 |

수확 직후에 다 파는 농가가 가장 싼 값을 받는 구조다. 저장고가 있거나 잘 말려 둘 수 있다면 일부를 늦여름 이후로 나눠 파는 편이 유리하다. 다만 저장 중 무름과 무게 손실이 있어 차익이 그대로 남지는 않는다. 저장용으로 캘 양파는 잎이 다 쓰러졌을 때, 바로 팔 양파는 70–80% 쓰러졌을 때 캔다. 매일 바뀌는 값은 [양파 가격·시세](/prices/onion/)에서 본다.

마늘을 함께 키운다면 [마늘 심는 시기 2026](/blog/garlic-planting-time-2026/)에서 형별 날짜를 같이 확인한다.

## 7. 체크리스트다.

- 동네 하루 평균기온이 15℃ 안팎으로 내려오는 때를 본다. 내륙은 10월 중하순, 남부는 11월 상순이다.
- 모종은 줄기 6–7.5mm, 키 25–30cm, 잎 4장을 고른다. 너무 굵은 모종을 일찍 심지 않는다.
- 한 판에 몇 구인지 보고 주당 값을 비교한다. 한 평에 약 110주가 든다.
- 퇴비·인산은 전량, 질소·칼리는 일부만 밑거름으로 넣는다.
- 3cm 깊이로 곧게 심고 흙을 눌러 준다. 늦게 심으면 조금 더 깊게 심는다.
- 겨울에 솟아오른 모종은 눌러 주고 흙을 덮는다.

## 8. 결론이다.

양파 심는 시기는 달력보다 기온이 정한다. 평균기온 15℃ 무렵, 연필 굵기 모종을 3cm 깊이로 심으면 대부분의 실패를 피한다. 빨리 심고 싶은 마음에 굵은 모종을 일찍 넣는 것이 봄 꽃대의 가장 흔한 원인이다.

사 먹는 쪽에서 보면 지금 양파 도매가는 1년 전과 비슷하고, 해마다 5–6월 햇양파 철이 가장 싸다. 키우는 쪽에서는 내년 6월에 한꺼번에 팔지, 저장해 나눠 팔지를 지금부터 정해 두면 품종 고르기도 쉬워진다.
